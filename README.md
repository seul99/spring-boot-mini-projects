## ✏️ 주요 문법 정리
**Thymeleaf** <br>
```th:text``` ->  태그안 데이터 출력<br>
```th:each``` -> 반복문<br>
```th:each = "${number:#number(시작번호, 끝번호)}"``` -> 시작번호~끝번호 빈복문<br>

<br>

**JPA Repository** <br>
```findBy(컬럼이름)``` -> 컬럼에서 키워드 넣어 찾기<br>
```findBy(컬럼이름)Containing``` -> 컬럼에서 키워드가 포함된것을 찾기<br>

<br>
